# Resume AI tells and replacements

Use this list during detection and rewrite. Prefer deletion or a concrete artifact over a fancy synonym.

## Ban or rewrite these verbs (openers)

| Avoid as default opener | Prefer when true |
| --- | --- |
| Spearheaded | Led, started, built, shipped |
| Leveraged | Used, applied, built on |
| Orchestrated | Coordinated, ran |
| Utilized | Used |
| Facilitated | Ran, hosted, unblocked |
| Championed | Pushed for, owned |
| Pioneered | Introduced, first shipped |
| Streamlined | Cut steps, removed handoff |
| Honed | Improved, practiced (usually delete) |
| Synergized | Coordinated [named teams] |
| Drove (with no object) | Grew, cut, shipped [named thing] |

Using "led" or "built" once is fine. Stacking five thesaurus verbs in one role is the tell.

## Ban these adjectives and slogans

results-driven, dynamic, passionate about, proven track record, seasoned professional, robust, seamless / seamlessly, cutting-edge, best-in-class, mission-critical, synergistic / synergies, detail-oriented (unless proven), self-starter, go-getter, thought leader, tapestry, delve, navigate the landscape, in today's fast-paced world, bottom-line results, operational excellence (unspecified)

Replace with a named system, a constraint, or a number the candidate can defend.

## Structural tells

- Three abstract adjectives + vague noun ("innovative, scalable, mission-critical solutions")
- Every bullet 14–18 words on the same grammar skeleton
- Em dashes used as decoration (replace with comma, period, or cut)
- Round-only metrics (exactly 10/20/25/30/50%) with no baseline
- Summary that works for any job title in the industry
- Seniority mismatch (language bigger than the role)

## Recruiter 6-second check

After rewrite, each role should answer:

1. What did this person actually touch?
2. With what tools or people?
3. What changed that someone else could notice?

If a bullet fails all three, rewrite or drop it.

## ATS-safe humanization

Keep: exact product names from the JD that the person used, standard headings, dates, job titles, location, skills list as a simple list.

Do not: keyword-stuff "Agile Scrum CI/CD microservices" into a sentence that is not true; hide keywords only in graphics; switch to a two-column layout "to look human".
